2026-10-14 通过公开 GET 获取 9 个入口及青春期家庭入口的男生、女生两个实际子页。获取不提交表单、不操作远端账号。原文、内联脚本、状态、字节数、SHA-256 见 `docs/evidence/native-migration/trackers-manifest.json`。页面脚本与表单是字段和计算依据，界面和持久化由本项目重新实现。

## 记录与报告

每个页签有独立记录，服务器以本人、工具、页签、日期保存；同一天同页签修改会更新，不覆盖其他页签。问卷工具仍保留每次完成记录。全部可浏览、删除、按月查看报告并备份/导入。

`server/tools/trackers.mjs` 根据真实记录计算：

- 共同指标为记录条数、记录天数、每个选项出现频次和文字反思。
- 4CR 保留高光、有效活动、主动平静比例和不足15天样本提醒；能力标签呈现次数，不把出现频次当作能力分数。
- 睡眠保留最近7条轨迹、平均时长与质量；区间按原站4.5至10.5小时代表值计算；5条起检测至少出现2次、平均质量差异达到0.4的因素线索，注明共现不代表因果。
- 数字产品保留时长、冲突、睡眠影响与服务效果自评汇总；亲子沟通保留家长/孩子情绪强度均值及实践文字。
- 饮食保留饮水、运动、执行度与测量轨迹。BMI和腰围身高比使用原始数学公式；原站年龄性别BMI界值为线性近似，本项目不把近似边界输出为医学诊断。

所有报告是描述性回顾，缺失项不按零分、缺失日不按良好计入。不同页签、年龄版不混成单一心理评分。

## 持久化、备份与边界

原站大部分将数据放在各自浏览器 localStorage；本项目迁入区域账号下 SQLite，跨设备以同一账号访问。管理员不能读取个人工具和日记数据。工具报告不进入关怀预警，预警仍只依据已确认的每日情绪打卡。

备份为向阳 v1 JSON，支持先完整校验、事务合并、按页签日期去重。导出不截断；大备份由客户端分批导入，客户端每批不超过100条和1MiB；服务器批次上限为2000条/2MiB。导入不相信外部 id、userId、result，报告重新计算；不直接兼容原站各自不同的 localStorage 备份格式。睡眠自定义因素通过“可能帮助睡眠”“可能影响睡眠”两个文本字段记录，未保留原站动态增删选项库。原站浏览器容量、备份提醒和分享/跳转入口由账号持久化、平台文件备份、内部页面替代。

`npm test` 包含真实 HTTP 验证：19工具57个年龄/页签版本的有效填写、即时报告、月报和隐私；同日更新、问卷多次作答、非法选项与日期、未知字段、事务导入、去重、伪造身份/结果拒绝、BMI公式、日记地图共现和服务表单区域隔离。问卷另有同原脚本1600组算法对比，见 `MIGRATION_QUESTIONNAIRES.md`。
