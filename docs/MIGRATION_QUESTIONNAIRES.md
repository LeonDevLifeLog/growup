# 成长现状与抗碎片化工具：本地迁移证据

日期：2026-10-14。范围为九个 Star-Track 成长现状工具，加共研室的抗碎片化工具。全部公开 HTML 以 GET 获取，未对参考站提交问卷、报名、同步或研究数据。证据在 `docs/evidence/native-migration/`；九工具清单与 SHA-256 见 `questionnaires-manifest.json`。

## 接口

`server/tools/questionnaires.mjs` 导出：

```js
import { questionnaireTools, evaluateQuestionnaire } from './server/tools/questionnaires.mjs';
const tool = questionnaireTools.find(tool => tool.id === 'ya');
const profile = tool.profiles.find(profile => profile.id === 'primary');
const answers = Object.fromEntries(profile.fields.filter(field => field.required)
  .map(field => [field.id, field.options[0].value]));
const report = evaluateQuestionnaire('ya', 'primary', answers);
// report.metrics[0] => { label: '综合观察分', value: 100, unit: '/100' }
```

工具字段符合约定的 `id/name/group/mode/description/sourceUrl/profiles`；版本含 `id/name/fields`。字段的 `section` 保留主题分组，`help` 为原站题目提示，版本 `description` 是原站填写说明。客户端应直接根据 options.value 提交原始类型，不把数字值转换成字符串。

题目字段为 `q0` 开始的连续编号。除抗碎片化外，选项 value 是原站零起始选项序号；抗碎片化使用源 Likert 数值 1–3、1–4 或 1–5。基本资料字段用 `name/grade/board/sleep/device/meal/body/waist`，按原版适用范围返回；补充文字均为选填，不参与计分。评估函数不进行外部请求；返回 `title/summary/metrics/sections/notice`。未知工具或版本、缺少必填、非法选项及超长输入抛带 `status=400` 的 Error。

## 评分与结果

| 工具 | 迁移的公开规则 |
| --- | --- |
| ya | 选项按 3、2、1、0 计分；七维分别归一到 100 并四舍五入；七维分数取平均并四舍五入。分项/综合界线 75、50。取最弱两个非良好维度，每维最多三条原站建议 |
| sm | 同样反向 3–0 计分；入睡、时长、安稳、日间、习惯五维；分项/综合 75、50；最弱两维各最多两条建议。基本作息资料不额外改变评分 |
| pm | 五维反向 3–0。分项 75、50；**综合 70、50**；总体描述按 85、70、50、0 分四档，而家长建议用综合三档。最弱三个非良好维度给建议；保留不同学段时长题及低分描述 |
| qz | 六维反向 3–0，版本有不同维度名称与题库；分项及综合 75、50；最弱三维建议；补充文字只回显 |
| ysd | 五维反向 3–0；分项及综合 75、50。最弱两维建议，加体型、腰腹、住校、就餐地点等原站条件提示。这些资料不额外改综合数值 |
| rj | 分项 75、55、35 三条界线产生四档；综合只平均核心维度，**家庭观察不计入综合**。综合描述用 75、50 两条界线。只从核心维度的“留意/关注”取最弱三维建议，家庭建议单独生成 |
| k1 | 按每题显式的 0–4 分表计分，不能直接用 3-index；牙齿/视力分别除各自满分得百分值，总体为两项百分值平均。等级界线 85、70、50，保留全部对应护理建议 |
| qcd | **不计算总分**。18 个真实答案传入初中/高中各自的六主题分支，产生“聊通/卡住/沉默”、解释及行动。保留六主题计数与原站“三件事”选取逻辑 |
| fxd | 五维反向 3–0；分项 75、55、35 四档；综合仅平均学习、生活、未来、迷茫四维，**家庭观察不计入综合**。总体描述界线 85、70、50；最弱两个核心维度各两条建议 |
| suipian | 选项取原始 Likert 数值；每维取均值，总体取所有题均值，再除该版本最大值。状态界线 0.8、0.6、0.4。保留四维描述与最低维度行动；全部维度≥0.8 时用保持行动。**遵照源界面只显示状态，不显示数值分数** |

原站建议和画像只是公开工具中的描述规则。本项目忠实迁移其计算，不表示已经独立验证了题库信效度、常模或医学有效性。报告统一保留非诊断说明，结果不与学校日常心情预警算法混用。

## 明确的适配与源问题

1. 原站多页在浏览器本机处理，抗碎片化页另有匿名研究提交。迁移后的评估只在本平台运行，由本平台统一保存，不向原站研究或评论 API 写入。原站“全程匿名/不上传”的承诺不自动沿用到本平台的实名账号存档。
2. 人际关系的走读/住校切换被展开为六个版本，保持场景题准确，避免客户端需要未约定的条件字段。
3. 青春期页补充文字原来没有显式 maxlength；迁移使用 5000 字输入上限，属于本平台输入保护，不是新评分规则。
4. `fxd.js` 的 `compute()` 返回 `per.parent`，但原站 `renderResult()` 读取 `res.parent`，会落入最低档家庭建议。迁移按真实计算出的家庭维度选择建议，修复这个字段引用错误；不复制误报行为。核心总分和全部维度分数与原站相同。
5. 原站课堂/医院身份、二维码、真实专业团队接单、研究上传及宣传文案不作为本地能力迁入；题目、输入、计算、报告与本平台持久化是本次迁移范围。

## 可重复验证

```sh
node scripts/extract-questionnaires.mjs --verify
```

脚本只读取本地捕获源，在不提供 DOM、网络和文件访问的隔离环境中取声明及纯函数。重新生成数据与青春期分支模块，并进行固定种子 1600 个对照案例：每版本首/尾选项及随机选项；九工具对照源 `compute()` 或分支函数，抗碎片化对照源均值、状态界线与描述表。另验证缺答及未知工具不能生成分数。

验证结果：32 版本、1600 案例通过，证据 `docs/evidence/native-migration/questionnaire-verification.json`。这是本地评分与分支一致性证据；不等于微信编译、真机流程、专业效度、正式研究或上线验收。
