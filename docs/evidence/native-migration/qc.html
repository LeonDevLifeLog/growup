核心理念

青春期是生命中最绚丽的拔节生长。我们相信：家长主动沟通、科学传授，方能护航孩子健康蜕变。以开放心态正视身心变化，积极拥抱成长，而非让孩子在网络不良信息中迷失。

❌ 避而不谈 回避话题，孩子只能从网络或同伴那里获取碎片化信息，容易产生羞耻感和焦虑，缺乏安全边界。
✅ 坦然沟通 开放讨论，科学认知，帮助孩子悦纳身体发育，学会自我保护，健康自信地度过青春期。

隐私至上，本地运行

青春期话题敏感而私密，本手册采用完全本地化架构，不联网、不上传、不留痕。孩子的隐私，只属于孩子自己。

  • ✓ 纯前端运行，无需联网，离线也能用
  • ✓ 数据不外传，没有第三方追踪
  • ✓ 家庭自主掌控，随时可以清除所有记录

简单使用说明

  • 1. 选择版本：根据孩子性别，点击进入“男生版”或“女生版”问卷。
  • 2. 共同填写：建议在轻松的氛围下，家长和孩子一起讨论每个问题，再勾选答案。
  • 3. 本地保存：填写完成后点击保存，数据只安全地存储在你当前使用的设备上。
  • 4. 持续追踪：建议每个月记录3-4次，长期坚持，你会看到孩子成长的清晰轨迹。
