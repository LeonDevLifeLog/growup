数据安全（重要）
⚠️ 数据存在哪里？
所有记录只保存在你当前这个浏览器的本机缓存里，不联网、不上传、不跨设备同步。
📱 微信 vs 浏览器数据不互通
微信内置浏览器和手机自带浏览器（Safari、Chrome 等）的缓存相互独立，数据不互通。建议固定在同一个入口使用，不要一会儿用微信、一会儿用浏览器。
💾 定期备份（每 30 天左右）
点「数据管理 → 备份」，会下载一个 JSON 文件。存到微信收藏、网盘或发给自己。
清理浏览器数据之前，务必先备份！
🔀 两端口数据怎么合并？
例如先在手机浏览器记了一些，又在微信里记了一些：
1️⃣ 在 A 端点「备份」，把文件发到 B 端；
2️⃣ 在 B 端点「导入/合并」，选择文件；
3️⃣ 选「合并」——两边的记录会自动去重合并。
（选「覆盖」会清空本机记录、完全使用文件里的数据，请谨慎。）
设计理念

这个手帐是为你设计的——一个可以安全存放自己声音的地方。和爸妈的沟通有时候会让我们感到困惑、委屈、或者不知道怎么说才好。

手帐的作用不是"评判对错"，而是帮你在安全的空间里：

📝 记录发生了什么 → ❤️ 看见自己的感受 → 💡 找到自己的声音
使用方法
1
日常对话：每次和爸妈发生了有印象的对话，打开「日常对话」面板，按步骤记录。不需要写得很完整，先记下来就好。
2
我的困惑：有些话可能一直憋在心里，或者不知道该怎么跟爸妈说。「我的困惑」面板提供了一个安全的地方，先写给自己看。
3
情绪滑块：拖动滑块表达你当时的情绪强度。0 = 平静，10 = 非常强烈。这能帮你觉察自己的情绪变化。
4
保存与导出：填写完当前面板后，点面板底部的「保存本次记录」写入本地；点「数据管理 → 备份」生成 JSON 文件，可发送给分析师获取专业建议。
一些想对你说的话
1
你的感受是真实的。无论你感到愤怒、委屈还是难过，这些情绪都值得被看见和尊重。不需要评判它们"对不对"。
2
沟通是双向的。有时候爸妈也在学习怎么更好地理解你。记录可以帮助你更清晰地看到双方在说什么、做什么。
3
你有表达的权利。你可以有不同意见，可以用平静的方式说出自己的想法。"我信息"是一个好用的工具："当你……的时候，我感到……，因为我需要……"
4
改变需要时间。沟通模式的改变不会一夜发生。每一次记录都是一次"看见"，而看见本身就是改变的开始。
