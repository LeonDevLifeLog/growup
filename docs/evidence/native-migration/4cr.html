📖 4CR成长手帐 · 使用说明
🌟 这是什么？
4CR成长手帐是一个不收集隐私的成长记录工具。它基于4C素质模型（独立思考、沟通、协作、创造力）+ 情绪恢复力（Resilience），帮助青少年、家长和老师记录日常的成长瞬间。
⚠️ 重要：数据存在哪里？
所有记录只保存在你当前这个浏览器的本机缓存里，不联网、不上传、不跨设备同步。
• 微信内置浏览器 和 手机自带浏览器（Safari、Chrome 等）的缓存相互独立，数据不互通。
• 建议固定在同一个入口打开使用，不要一会儿用微信、一会儿用浏览器。
• 清理浏览器数据、卸载微信/浏览器、更换手机，记录都会永久丢失。
💾 定期备份（非常重要）
建议每 30 天左右备份一次：点「数据管理 → 备份」，会下载一个 JSON 文件。
把文件存到微信收藏、网盘，或发给自己，换设备时用「导入/合并」即可恢复。
⚠️ 清理浏览器数据之前，务必先备份！
🔀 两个端的数据怎么合并？
例如先在手机浏览器记了一些，又在微信里记了一些：
1️⃣ 在 A 端点「备份」，把 JSON 文件发到 B 端（微信文件传输助手 / 邮件都行）；
2️⃣ 在 B 端点「导入/合并」，选择文件；
3️⃣ 弹窗里选「合并」——两边的记录会自动去重合并，都不会丢。
（若选「覆盖」，则会清空本机记录、完全使用文件里的数据，请谨慎。）
👦 青少年视角
情绪天气：每天花1分钟，选一选今天的情绪状态，再选"能不能较快让自己平静下来"，也可以写一写发生了什么。
4C+R成长瞬间：每周2-3次，记录让你觉得自己在成长的瞬间，可以标记为高光时刻⭐
本周想一想：每周1次，根据提示问题想一想、写一写。
👁️ 家长视角
用"我注意到…"的方式记录孩子的具体行为，不用评价性的词语。选择情境和关联的能力维度。
🎪 活动反馈
记录参加线下或线上活动后的效果，勾选是否看到了好的变化。
🌿 压力分析
记录自己感受到的压力信号（情绪、身体、行为等）和关联情境，帮助觉察压力来源。
📊 报告与数据
至少记录15天后可以生成月度成长报告。数据只存在你的浏览器里，请定期备份。导出数据文件后可以发给分析师，获取专业解读。
⚠️ 确定要清空所有记录吗？
清空后无法恢复！
请先点「备份」导出文件再清空。
📥 选择导入方式
合并：保留本机记录，只补充文件里的新记录（推荐）
覆盖：清空本机记录，完全使用文件里的数据
📋 月度成长报告
报告仅含本月数据。完整备份请到「数据管理 → 备份」。
