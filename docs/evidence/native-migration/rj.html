设计理念

人际关系是孩子成长中的重要课题，但不同年龄段面临的挑战截然不同。小学阶段重在建立友谊、融入集体、学习分享与合作；初中阶段需要面对青春期社交变化、同伴压力与自我认同；高中阶段则涉及更深层的自我探索、情感关系与未来规划。

本工具基于发展心理学与人际关系研究设计，通过观察而非评判的方式，帮助家庭看见孩子真实的社交状态，发现那些未被表达的困扰，学习如何成为孩子成长路上的支持者而非评判者。
