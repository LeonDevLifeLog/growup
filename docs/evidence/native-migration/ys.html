🔍 体格综合评估

保存测量数据后即可查看评估结果

BMI 说明：BMI = 体重 ÷ 身高²。青少年的BMI需要结合年龄和性别来评估，建议参考WHO或中国儿童青少年生长发育标准。

WHtR 说明：腰围身高比 = 腰围 ÷ 身高。WHtR 是评估中心性肥胖的关键指标，不受年龄和种族影响，临界值为 0.5。≥ 0.5 提示中心性超重，≥ 0.55 提示中心性肥胖。中心性肥胖意味着内脏脂肪过多，比全身性肥胖危害更大。

🔬 中心性肥胖与偏瘦专题

⚠️ 中心性肥胖 — 最危险的肥胖类型
中心性肥胖是指脂肪主要堆积在腹部（内脏脂肪），表现为"苹果型"体型——肚子大、四肢相对较细。即使BMI在正常范围内，如果腰围身高比 ≥ 0.5，也意味着代谢风险显著升高。
危害 胰岛素抵抗 → 2型糖尿病前期
危害 脂肪肝 → 肝功能异常
危害 血脂异常 → 心血管风险升高
危害 生长激素分泌抑制 → 影响身高
关键 腰围身高比(WHtR) ≥ 0.5 即需干预
📐 偏瘦 — 被低估的生长隐患
偏瘦不仅影响身高发育和免疫力，还会导致体力不足、注意力涣散，尤其在学业繁重时更易疲劳。腰围身高比 < 0.43 往往伴随营养不足信号。
影响 身高增长潜力未能充分发挥
影响 免疫力低下 → 频繁感冒生病
影响 肌肉量不足 → 体力差、体育落后
影响 青春期发育迟缓（女：闭经风险；男：第二性征延迟）
注意 需排查：挑食偏食、消化吸收不良、甲状腺功能亢进、刻意节食
🥗 WHtR 分级参考（青少年通用标准）
WHtR < 0.43 → 偏瘦型 — 关注营养不足
WHtR 0.43–0.49 → 正常 — 继续保持
WHtR 0.50–0.54 → 中心性超重 — 需积极干预
WHtR ≥ 0.55 → 中心性肥胖 — 建议就医评估
💡 腰围正确测量方法：被测者站立，双臂自然下垂，暴露腹部。测量者用软尺在肚脐水平位置绕腹一周，软尺紧贴皮肤但不压迫，在正常呼气末读取数值。建议每次由同一人、同一时段测量，以减少误差。

从"管住嘴"到"科学滋养"

守护青少年健康成长 · 营养师协作
📖 简单使用说明
1. 饮食记录：按需记录，不用每天打卡。可以记一餐、一天，或者特殊事件（比如聚餐/暴食），重点是慢慢找到规律。
2. 体重身高：每周或每两周固定时间测量一次，务必同时测量腰围，以评估中心性肥胖风险。
3. 成长轨迹：随时查看历史记录和综合分析。
4. 营养咨询：记录营养师给建议和执行情况。
5. 导出分析：积累一定数据后（比如15条记录），导出JSON发给专业人士。
6. 数据安全：数据只保存在当前浏览器（微信和手机浏览器互不相通，请固定用一个入口）。每30天左右在「💾 数据备份」中导出一份；换手机、清理手机缓存或浏览器数据前，务必先备份。
青春期是生长发育的关键窗口期，饮食不仅影响当下的体重和体能，更会影响成年后的健康基础。然而，"管住嘴"式的粗暴干预往往适得其反，容易引发逆反和饮食障碍。

「成长食光」相信：饮食是观察青少年身心状态的窗口。我们用专业的数据记录和分析，支持家长与营养师协同，陪伴孩子度过关键成长期。
🌿 灵活记录观
不必强求每餐都记，完美主义反而容易放弃。关注"关键场景"和"长期趋势"才是核心。
按需记录 记住特殊的聚餐、住校期间的饮食概况、情绪性进食就可以了。偶尔漏记完全正常，能捕捉到饮食模式和问题比形式上的连续更重要。
🥗 全场景饮食观
青少年的饮食发生在多个场景：家庭餐桌、学校食堂、住校宿舍、街边小吃、外出聚餐。每个场景都有不同的营养挑战。
家庭 最可控的场景，是建立健康饮食基础的好地方。

食堂 走读生午餐的主要场景，注意荤素搭配和油盐多少。

住校 自主权变大，零食和含糖饮料是主要风险点。

外食 高油高盐高糖的集中暴露场景，注意控制频率。
😌 情绪与饮食解码
青少年暴食、挑食、零食依赖，往往不是"馋"，而是情绪的表达。考试压力、社交焦虑、青春期波动，都会通过饮食行为表现出来。
先理解，再调整 记录进食前后的情绪。试着把"别吃了"换成"今天是不是压力有点大？"。先理解情绪，再调整饮食。
📈 长期追踪思维
一天的饮食不能定义健康，长期模式才是关键。体重身高需要结合年龄、性别、青春期阶段综合评估，避免简单的"胖瘦"标签。
关注趋势，而非单点 关注体重身高的变化趋势而不是单次的数值。青春期快速长个子时体重增加是正常的，关键是增长速度是否合理。
⚠️ 中心性肥胖 — 比BMI更重要的指标
BMI无法区分"肌肉重"和"脂肪重"，也无法反映脂肪的分布位置。而脂肪堆积在腹部（内脏脂肪）比堆积在皮下危害大得多。
核心指标 腰围身高比（WHtR）= 腰围 ÷ 身高，临界值 0.5，不受年龄种族影响

为什么重要 中心性肥胖直接关联胰岛素抵抗、脂肪肝、血脂异常。很多BMI"正常"的孩子实际上已经是中心性肥胖

行动建议 每次测体重时同时测量腰围，关注WHtR的变化趋势比关注体重绝对值更有意义
📐 偏瘦不是"省心" — 低体重的隐匿风险
很多家长觉得孩子偏瘦"不用操心"，但持续的低体重可能意味着营养摄入不足、消化吸收障碍甚至内分泌问题。
生长风险 身高增长有窗口期，营养不足会让遗传潜力"打折扣"

免疫风险 偏瘦孩子反复感冒、注意力差，常被误认为"体质差"而非"营养差"

排查要点 挑食偏食？消化不好？刻意节食？甲亢？需逐一排查
📱 数据存在哪里？如何跨端使用？
所有数据保存在当前浏览器的本地存储中。微信内置浏览器与手机浏览器（Safari/Chrome）是两个独立空间、互不相通；换手机、卸载浏览器、清理缓存都会导致数据丢失。
建议 固定使用同一个入口记录，避免两边交替记录导致数据分散

备份 每30天左右导出一次完整备份，留一份JSON文件

合并 两端都有记录时，用「💾 数据备份 → 导入合并」汇总，相同记录自动去重

警惕 清理手机缓存 / 浏览器数据 / 微信存储空间前，先备份！
