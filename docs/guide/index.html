GUIDE · 按你的身份阅读

成长健研社，怎么用？

系统里有四种身份，每种身份能看到的页面和能做的事不同。先找到你的身份，只读和自己有关的部分即可。每一步都写了要点击的按钮名称，与页面上的文字一致。

网页 · 小程序 我是学生 用学校给的邀请码注册，记录心情、写星图日记、在树洞说说心事、需要时申请支持。 网页后台 我是学校管理员 为本校开通学生注册，关注本校学生状态，审核树洞，回复学生的支持需求。 网页后台 我是大区管理员 查看本区所有学校的关怀情况，任命和调整本区的学校管理员。 网页后台 我是平台管理员 首次安装系统，开通大区和学校，任命各级管理员。不查看学生关怀数据。

学生

网页：打开学校告诉你的网址 · 小程序：搜索“成长健研社”

第一次使用：用邀请码注册

  1. 向老师要一个学校邀请码（一串英文和数字）。
  2. 网页点右上角 登录 / 注册，小程序直接在首页操作；选择你学校所在的大区，切到 邀请码注册。
  3. 填入邀请码，点 核对学校，确认显示的是自己的学校。
  4. 填写称呼，自己设置账号和密码（再输入一次确认），完成注册。以后用这个账号密码登录，记得选同一个大区。

日常可以做什么

第一次登录后，首页会显示 从这里开始 三个小步骤；小程序随时可以在 我的 → 使用帮助 再看这份说明。

记录今天的心情

首页点 记录今天的心情，选一个最接近的表情，可以加标签和几句话。一天一条，再提交会更新当天的记录。

写星图日记

在 我的星图 写日记、加生活标签。经常一起出现的标签会连成你的星图。

在树洞说说心事

用化名写纸条，老师审核后才会给同区同学看到。也可以给别人送温暖、回应。不要写真实姓名、学校、电话。

申请支持

网页点右上角自己的名字进入个人页 → 提交新需求；小程序 我的 → 服务需求与处理状态。老师跟进后，会在这里看到回复。

谁能看到我的内容？日记和心情备注只有你自己能看。老师只能看到心情分数，用来及时关心你。树洞纸条显示化名。

修改密码 · 忘记密码

网页点右上角自己的名字进入个人页 → 修改密码；小程序 我的 → 修改密码。

忘记密码时，请联系本校老师在后台帮你重置。重置后第一次登录，系统会请你设置一个只有自己知道的新密码。

需要立即帮助？树洞和支持申请需要老师人工处理，不能即时救援。遇到危险，请马上联系身边信任的大人或当地紧急服务。

学校管理员

管理范围：本校

第一次登录

  1. 在网址末尾加上 /#admin 打开管理后台，点 登录管理后台。
  2. 保持 大区 / 学校登录，选择学校所在大区，输入上级给你的账号和初始密码。
  3. 系统会要求你先设置自己的新密码（不能和初始密码相同），设置后进入后台。
  4. 看 关怀概览 顶部的 今天先做这几件事，按顺序完成即可。侧栏上的红色数字表示该页面还有多少待处理。

为学生开通注册

  1. 左侧 学校与邀请 → 右上角 生成邀请码。
  2. 填写备注（例如“高一年级”）、有效天数和注册名额，点 生成邀请码。
  3. 完整邀请码只显示这一次：点 复制邀请码，通过班级群等学校渠道发给学生，再点 我已记录。
  4. 在邀请列表点 使用记录 查看哪些学生已注册。邀请码泄露或不再需要时，点 停用；已注册的学生不受影响。

日常工作

关注学生状态

  1. 学生关怀 用颜色标出需要关注的学生（见关怀提示规则）。
  2. 点 查看 打开学生详情，看近期心情。
  3. 与学生沟通后，在详情底部写 添加跟进记录。

审核树洞

  1. 树洞审核 的 待审核 列出待处理的纸条和回复，侧栏会显示数量。
  2. 内容合适点 审核通过；不合适点 驳回，确认后不会公开。
  3. 已发布的纸条也可以 下架纸条。驳回后仍可在 已驳回 中重新通过。

回复支持需求

  1. 支持需求 默认显示 待跟进。
  2. 实际联系学生或家长后，点 标记已跟进，写一段处理说明。
  3. 学生会在“我的”里看到这段说明。标记后不能撤回，请确认已经处理。

帮学生找回账号

  1. 用户管理 搜索学生账号或称呼。
  2. 点 重置密码，设置一个临时密码并告诉学生。
  3. 学生下次登录会被要求改成自己的密码。毕业或离校可点 停用。
想增加一位老师一起管理？在 用户管理 点 新增工作人员 为他建账号，然后请大区管理员把他任命为学校管理员。学校管理员不能任命管理员。

大区管理员

管理范围：本大区的所有学校

登录方式和学校管理员相同（选择本大区）。关怀概览、学生关怀、树洞审核、支持需求 的用法与学校管理员一致，只是范围扩大到全区所有学校。学校与邀请 只能查看各校邀请的使用情况，邀请码由学校管理员生成。

为学校安排管理员

  1. 用户管理 → 新增工作人员：填写称呼、账号、初始密码，可以直接选择所属学校。
  2. 在列表中找到这位工作人员，点 任命为学校管理员，选择要管理的学校，确认。
  3. 把账号和初始密码通过可靠渠道交给本人；对方首次登录会被要求修改密码。
  4. 人员调整时，对学校管理员点 撤销管理员：账号保留在原学校，变为待授权，登录状态立即失效。
范围说明你只能任命学校管理员，不能任命其他大区管理员或平台管理员，也看不到其他大区的人员。需要调整大区管理员，请联系平台管理员。

平台管理员

管理范围：全平台的组织与账号（不含学生关怀数据）

首次安装：在浏览器里初始化

  1. 服务启动后，用浏览器打开站点，会自动出现 首次安装初始化 向导。若部署人员设置了初始化口令，在第一步输入。
  2. 创建平台管理员：称呼、登录账号、密码（输入两次）。
  3. 可以顺手填写第一个大区和学校，也可以 跳过，稍后创建。
  4. 完成后自动登录。向导只能使用一次，之后不再出现。

按“开通进度”开通系统

平台管理 顶部的 开通进度 清单会告诉你下一步做什么，点当前步骤的按钮直接进入对应操作：

  1. 新增大区：大区 页签 → 新增大区。
  2. 新增学校：学校 页签 → 新增学校，选择所属大区（创建后不可迁移）。
  3. 建立工作人员账号：左侧 用户管理 → 新增工作人员。新账号是“待授权用户”，还不能登录。
  4. 任命管理员：管理员 页签 → 任命管理员，搜索并选择刚建的账号，选择角色和管理范围。
  5. 之后由学校管理员生成邀请码、学生注册，清单全部完成后自动收起。

调整或撤销管理员

管理员 页签中点 调整权限 改角色或范围，点 撤销权限 收回。调整后对方需要重新登录。

停用大区或学校

在对应页签点 停用。停用后该范围的账号立即退出、不能登录，学生也不能再注册；历史数据保留，可以重新启用。

查看操作记录

操作记录 页签显示最近 100 次组织和人员变更，记录不含任何密码。

备份与升级

由运维人员按部署文档执行，备份文件包含学生个人数据，请严格控制访问。

关怀提示规则

颜色是交流的线索，不是诊断。

提示 什么时候出现 建议
优先关怀 连续 5 天及以上心情为 1–2 分 尽快当面或电话了解情况，必要时联系家长和专业人员。
需要关注 连续 3–4 天心情为 1–2 分 找合适的时机轻松聊一聊。
状态平稳 最近连续 7 天心情都在 3 分及以上 保持日常关注。
观察中 / 待补充记录 / 样本不足 其他情况，或超过一天没有记录、尚未打卡 没有记录不代表状态良好，可以提醒学生记录。

按北京时间的自然日计算；当天更新不增加天数，中断一天会重新计算。写了跟进记录不会消除提示，提示随学生后续的记录变化。

常见问题

登录时提示“该账号不属于所选区域”

账号绑定在学校所在的大区。请在登录页选择正确的大区；平台管理员请切换到 平台管理员登录，不需要选择大区。

提示“账号尚未分配访问权限”

这是一个待授权的工作人员账号，需要大区管理员或平台管理员任命后才能登录。

提示“账号或所属机构已停用”

你的账号、学校或大区被停用了。请联系上级管理员确认。

邀请码核对失败

邀请码可能已过期、名额已满或被停用，也可能选错了大区。请向学校老师确认，必要时请老师重新生成。

忘记密码怎么办？

系统不提供自助找回，以保护账号安全。学生请找本校老师，管理员请找上级管理员，在 用户管理 中重置。重置后首次登录需要设置新密码。

为什么用户管理里看不到某些人？

你只能看到自己范围内、比自己低一级的账号。例如学校管理员看不到其他学校的学生，也看不到大区管理员。

关闭弹窗时提示“放弃未保存的内容？”

你填写的内容还没有保存。选 取消 可以回到弹窗继续填写。
