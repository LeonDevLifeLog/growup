# 成长健研社 · 微信原生小程序

使用原生 WXML、WXSS、JavaScript 与微信原生导航、输入框、选择器和弹窗，直接调用与网页端相同的 API。不是 web-view 套壳。

## 本地启动

1. 在仓库根目录启动 API：`npm start`，按根目录 README 初始化平台、开通学校和学校管理员，再由学校生成邀请码；虚构数据体验显式使用 `DEMO_MODE=1 npm start`（需要 Node.js 22.13+，具体以根目录 README 为准）。
2. 微信开发者工具中导入本目录 `miniprogram/`。项目配置使用自己的微信 AppID，本地个人工具配置不用于服务器部署。
3. 唯一 API 地址配置在 `config.js`，默认 `http://127.0.0.1:8787/api`。本地开发配置 `urlCheck: false`；如工具仍阻止请求，在开发设置中勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。此设置只用于本地开发。
4. 显式启用演示模式后，可使用海南学生 `hainan.student` / `Growup123!`；也可用学校邀请码 `HN2026`、`SD2026`、`GD2026` 注册对应区域的学生账号。演示开关关闭时不显示“填入演示账号”按钮。

真机中的 `127.0.0.1` 指手机自身。真机联调需将 `config.js` 改为同网段电脑地址，并使 API 可通过局域网访问。正式发布需真实 AppID、可用的 HTTPS API 域名与微信后台的 request 合法域名白名单；不得把开发环境的不校验域名设置当作发布配置。

## 页面与功能

| 页面 | 原生功能 |
| --- | --- |
| 登录 | API动态大区、账号密码、核对学校与确认密码的邀请注册、服务器跨区登录校验 |
| 今日 | 当日心情入口、累计/连续记录、最近 7 次心情、本区域和本人资料 |
| 心情 | 5 级心情、最多 6 个标签、私人备注、当日更新与支持性反馈 |
| 探索 | Star-Track、STARMAP、校园/家庭服务、技能输出、4 类理念、2 个共研室、合作生态与联系 |
| 内容阅读 | 成长理念、18 个本地工具、校园学生/教师需求调查、服务反馈、页面反馈 |
| 成长工具 | 18 个观察/自评工具与抗碎片化调查、版本切换、保存、tracker 回填修订、历史删除、即时结果、月报、JSON 备份 |
| 星图 | 完整/一句话/仅心情、强度/标签/目标、私人关系图、搜索删除、选择片段 JSON 备份、生成与保存星图图片 |
| 树洞 | 本区域主题筛选、化名投稿、公开回应、每日温暖、举报隐藏、我的待审/公开/驳回状态 |
| 服务需求 | 类型选择、需求提交、本人申请与处理状态 |
| 我的 | 资料、学校与区域、隐私、求助提示、退出登录并撤销服务端会话 |

底部 5 个原生 Tab：今日、探索、星图、树洞、我的。管理员使用独立网页后台，小程序不提供管理员注册或管理入口。

Tab 图标随小程序打包在 `assets/tabbar/`，每个入口包含普通灰绿色和选中深绿色两张透明 PNG，尺寸均为 81 × 81。图标使用 Lucide，许可见该目录 `LICENSE`。需要重新生成时，在仓库根目录执行 `node scripts/generate-tab-icons.mjs`（使用已安装的 Chrome）。

成长工具通过服务端统一字段 schema 在原生页面内填写，直接保存本人记录、生成本人回顾并查看历史。校园需求调查和反馈同样通过原生表单提交给本区域后台，不跳转外站。成长健研社官网与小程序使用统一品牌和产品介绍。工具结果用于描述性成长回顾，不作医学诊断。

日记与工具备份以成长健研社 v1 JSON 格式导出。小程序通过文件系统写入本地，并在微信支持时调用文件分享；导入使用聊天文件选择器读取 JSON，由服务端仅合并本人的合法记录。已有v1备份继续适用；官网早期浏览器版本的备份格式与账号备份不同。

导入支持不超过 50 MiB 的 JSON 文件，每批不超过 100 条且请求体不超过 1 MiB。发生中断会显示已处理数量，可重试同一备份并由服务端去重。导出日记前可勾选片段；未选择时导出全部本人日记。星图图片先在原生 canvas 绘制，再生成图片并由用户点击保存到相册，图片不含日记正文。

树洞匿名仅指对其他学生匿名；平台保存关联用于人工审核与举报追溯。帖子和回应先审后发，没有私信、公开排名或陌生人联系。日记、心情备注仅本人可见；本区大区管理员及本校学校管理员可查看心情分数与日期用于人工关怀。数据访问控制在服务端实现。

## 验证范围

在仓库根目录执行：

```sh
node miniprogram/validate.mjs
node miniprogram/validate.mjs --require-wcc
node miniprogram/api-smoke.mjs
node tests/mini-enrollment.mjs
```

`validate.mjs` 检查 JSON、页面文件、原生 Tab 路径与两种状态的本地 PNG（路径、尺寸、体积及状态差异）、JavaScript 语法、事件绑定、导航目标、WXML 运算符和原生标签。工具目录与字段统一来自 API，小程序不重复维护问卷 schema。如存在微信开发者工具内的 `wcc`，脚本还会调用真实 WXML 编译器；可设置 `WCC_PATH`，或通过 `--require-wcc` 要求编译器存在。缺少编译器时会明确报告仅完成结构检查。

`api-smoke.mjs` 创建独立临时 SQLite 与 API，在 Node 中执行原生 Page 事件，校验工具各版本保存/回顾/删除、日记与星图、结构化服务表单。它不会连接正在使用的数据库，也不模拟微信控件、文件选择器或真机。

真实 WXML 编译不等同于微信开发者工具完整构建、运行或真机交互。具体执行结果见任务验证记录；文件选择分享、微信控件和真机仍需单独验证。

导入工具后应实测：选错区域拒绝登录 → 正确区域登录 → 当日打卡并更新 → 私人日记 → 树洞投稿待审 → 网页后台审核 → 刷新公开纸条 → 回应/温暖/举报 → 服务申请 → 退出和重新登录。还需校验小屏、键盘弹出、断网错误与重复提交禁用。

上线仍需完成真实学校名单与邀请码、监护人授权和隐私告知、人工审核与关怀人员、服务器部署与备份、通知渠道。正式上线配置与流程参见 `../docs/PRODUCT.md`。
